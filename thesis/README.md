# thesis: the LaTeX text (module 5, notes collected all year)

English, IEEE citations. Structure follows the UGent FEA form rules (see `notes/outline.md`).

```
thesis/
  main.tex            from the UGent FEA template (Overleaf: "Master's Thesis Ghent University Faculty of Engineering and Architecture")
  chapters/           one .tex file per chapter
  figures/            generated by scripts/make_figures.py, never edited by hand
  extended-abstract/  2-6 page paper (IEEE conference template)
  references.bib      exported from Zotero
```

The template is added when writing starts. If you write in Overleaf, link it to this folder with Overleaf's Git integration.
